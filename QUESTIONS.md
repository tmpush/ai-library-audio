# Решения и ожидаемые вводные

## Принято
- До двух разных машин; повторная активация той же машины идемпотентна.
- Серверная проверка при старте и каждые 24 часа. При недоступном сервере разрешение действует максимум 7 дней после успешной проверки, но не дольше подписки.
- Отзыв онлайн применяется при очередной проверке; офлайн невозможно гарантировать отзыв за 24 часа.
- Исходный текст сохраняется. Преобразования относятся только к версии для синтеза.
- Русский интерфейс, светлая и тёмная темы.
- Подписка месяц/год, без лимита книг/минут. Ключи выдаются вручную. Отвязка администратором.
- Модели без лицензионных платежей, голосовое клонирование обязательно.

## Позже необходимо
- Подтверждение загрузки получено 28.10.2026: «Да, скачать и проверить». Qwen3-TTS 0.6B Base (2 516 100 892 байта) полностью скачан и проверен; TTS установлен в `.venv-tts`, реальные WAV получены на CPU и CUDA. Повторно спрашивать разрешение на эту модель не нужно.
- Реальный разрешённый образец голоса 15–30 секунд для слуховой проверки клонирования; желательно с точной расшифровкой.
- Windows GPU уже обнаружен: NVIDIA GeForce RTX 4070 SUPER, 12282 MiB. Повторно уточнять его не нужно.
- Доступ к подготовленной сборочной машине/CI и Mac Intel/Apple Silicon для установщиков и измерений. Rust/MSVC на текущем ПК отсутствуют; запрет менять системные компоненты сохранён.
- VPS, домен и сертификаты подписи приложений для выпуска.
- Приёмка на реальных книгах: искусственные книги не покрывают разнообразие издательской разметки.

Дополнительные продуктовые вопросы сейчас не блокируют разработку: для всех остальных пунктов приняты рекомендованные варианты из PLAN.md.
