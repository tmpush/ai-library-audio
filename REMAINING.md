# Остаток работ для передачи Lunatica заказчику

Обновлено 7 ноября 2026. Продукт предназначен для личного использования заказчиком; публичный SaaS, платежи и регистрация не требуются. Нативный Rust-интерфейс сохраняется. Лицензирование остаётся под контролем разработчика. Русский — ESpeech RL-V2 с ударениями, английский — Qwen.

## P0 — до передачи заказчику

1. Развернуть License API на сервере разработчика с HTTPS, постоянным адресом и резервным копированием базы/ключа подписи; закрыть доступ заказчика к администрированию. Текущий localhost подходит только для разработки. Админка, выпуск/продление/отзыв, 2 устройства, подпись Ed25519 и 7 дней офлайн реализованы. Пересобрать клиент с публичным адресом и ключом проверки, проверить активацию на машине заказчика.
2. Согласовать срок доступа и момент выдачи ключа относительно оплаты. Офлайн-разрешение действует до 7 дней, немедленного отзыва без интернета нет. Локальная защита не гарантирует невозможность взлома; секрет подписи и админский доступ не передавать с клиентом.
3. Выпустить окончательный установщик Windows с актуальным интерфейсом и адресом сервера. Локальный установщик с ESpeech runtime уже собран в `dist/installers/pre-redesign-06e1ef6`, но он предшествует последним правкам интерфейса; сборку CI ещё нужно обновить для ESpeech. Организовать отдельную установку/проверку весов ESpeech, Vocos и Qwen без путей компьютера разработчика. Проверить на чистой Windows без Python/Rust и на реальной машине заказчика.
4. Пройти сценарий в установленной программе: импорт → запись/выбор голоса → проба → глава → исправление фрагмента → MP3/M4B → перезапуск и продолжение. Проверить записанный текст и короткие образцы; старым длинным профилям нужна новая запись или точно размеченный короткий образец.

## P1 — устойчивость и качество

5. Длинная русская книга на ESpeech: несколько глав, одинаковый голос/громкость, имена, омографы, числа, латинские X и сокращения. Слуховая проверка автоматических ударений и ручных переопределений. Сравнить качество встроенных дикторов и голоса заказчика. Короткие пробы не доказывают качество целой книги.
6. Повторить VRAM/OOM, паузу/продолжение и перезапуск именно с ESpeech. Проверить сохранность готовых фрагментов при сбое/нехватке диска и переключение RU/EN в смешанной книге. Базовый механизм очереди уже есть, ранее проверялся с Qwen.
7. Проверить общий сервер: истечение срока, отзыв, третий компьютер, отвязку устройства, 7/8-й день офлайн, неверную подпись и восстановление сервера из бэкапа. Старые автоматические проверки не заменяют приёмку развернутого сервера.
8. Проверить экспорт длинных MP3/M4B с обложкой и оглавлением в проигрывателе заказчика, скорость и свободное место на его оборудовании.

## P2 — по потребности заказчика

9. Уточнить, нужен ли Mac и какой процессор. Если нужен — обновить DMG/PKG с ESpeech, проверить микрофон, CPU-скорость и локальный сценарий на реальном Mac. Старый установщик ESpeech не содержит; ускорение MPS для него не реализовано.
10. Документировать передачу, обновление, восстановление библиотеки и ограничения лицензий. Добавить проверяемые резервные копии проектов/голосов. При необходимости оформить подпись Windows и Developer ID/нотариализацию Mac.

Не включаем в обязательный объём SaaS-биллинг, публичные тарифы и регистрацию пользователей. Бесплатные встроенные голоса уже созданы; расширение набора — по запросу.
