# Lunatica — варианты логотипа

Три концепта созданы встроенным image_gen. Выбран вариант 1: луна из страниц. `icon-master.png` — исходник иконки для Windows и macOS. PNG, ICO и ICNS экспортированы в `client/native/assets`.

1. `01-moon-pages.png` — луна из книжных страниц.
2. `02-orbital-ribbon.png` — геометрическая лента.
3. `03-literary-monogram.png` — монограмма L с лунным вырезом.

Палитра: графит, белый и светло-фиолетовый. Существующие каталоги приложения, идентификаторы и ключи лицензий сохранены для совместимости обновлений.

## Промпты

### 1

Use case: logo-brand. Create a polished single concept presentation for Lunatica, a desktop audiobook studio for cloning your own voice and reading books. Concept 01: a precise crescent moon formed from two turning book pages, restrained elegant editorial geometry, memorable at small size. Flat vector-like mark, no gradients, no stars, no microphone. Lavender #C7AFF0, charcoal #242326, white. Landscape brand board with large lavender mark and exact wordmark "Lunatica" on charcoal, a smaller white-background version and one app icon sample. Refined literary serif wordmark, careful kerning. Spacious professional graphic design, no other text or invented slogan. This must be one cohesive concept, not multiple alternatives.

### 2

Use case: logo-brand. Create a polished single concept presentation for Lunatica, desktop audiobook studio. Concept 02: distinct custom lowercase letter l that folds into an orbital crescent, a geometric continuous ribbon subtly implying sound and a page, strong simple silhouette, premium contemporary software identity. Flat vector-like, no gradients, no microphone, no stars, no generic waveform bars. Lavender #C7AFF0, charcoal #242326, white. Landscape brand board with large mark and exact wordmark "Lunatica" on charcoal, a smaller white-background version and one app icon sample. Humanist clean sans-serif wordmark. Generous whitespace, precise alignment. No text besides Lunatica. One cohesive concept.

### 3

Use case: logo-brand. Create a polished single concept presentation for Lunatica, desktop audiobook studio. Concept 03: a bespoke literary capital L monogram with a crescent moon cut out of its upper serif, sculptural but flat simple bold silhouette, sophisticated book publisher meets audio studio. No gradients, no stars, no microphone. Lavender #C7AFF0, charcoal #242326, white. Landscape brand board with large mark and exact wordmark "Lunatica" on charcoal, smaller white-background lockup and one app icon sample. Expressive modern high-contrast serif wordmark with restrained spacing. Spacious art direction, no text besides Lunatica. One cohesive concept.
