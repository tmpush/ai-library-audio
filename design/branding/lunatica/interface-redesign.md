# Lunatica: рабочая студия аудиокниг

Направление: Consumer Creator Tool + Minimal Editorial Product. Нативный Rust / egui; русскоязычный пользователь, основной сценарий — книга → свой голос → проба → глава или книга → исправление → экспорт.

Постоянная навигация слева; библиотека в виде строк с небольшими обложками, автором и состоянием; студия — текст слева и последовательные настройки справа. Запись голоса и готовые версии доступны отдельными пунктами. Никаких декоративных метрик или маркетинговых блоков.

## Источники и ограничения

Использован ui-ux-pro-max: design-system и поиск UX навигации. Поиск design-system вернул маркетинговые структуры и посторонние палитры: они отклонены как неподходящие desktop-продукту и ранее выбранному бренду. Общие рекомендации контраста, иерархии, видимого фокуса и разделения этапов применены. Для egui отдельного стека в навыке нет; веб-код не переносится в приложение.

Проверка: настоящая установленная Windows-программа, тёмная и светлая темы, библиотека, студия, голоса, записи и настройки. Целевой минимум окна 1000×720.

## Результат проверки

- Сборка Windows release прошла; программа установлена и запущена.
- `cargo test --locked`: 1 passed (контракт записи WAV). Новые зеркальные UI-тесты не добавлялись.
- В установленной программе визуально проверены библиотека, студия, голоса, готовые записи и настройки. Проверены обе темы. Исправлены выход текста мини-обложек за края, ширины столбцов и перенос основной кнопки.
- Контраст: тёмный основной 13.11:1, вторичный 7.09:1; светлый основной 15.37:1, вторичный 6.03:1; основная кнопка 7.65:1, выбранный пункт светлой темы 6.42:1.
- Минимум 1000×720 сохранён в настройках окна; точное уменьшение окна до этого размера инструментом UI не удалось, поэтому этот размер отдельно не подтверждён визуально. Проверенный размер 1362×952 с рамкой Windows. Полный аудит экранного диктора не проводился.
- Оценка по anti-ai-slop-ui (экспертная, не автоматический замер): AI Slop 2/10, Distinctiveness 8/10. Остаточный компромисс — стандартные egui-комбобоксы; панели студии при небольшой высоте доступны прокруткой.
- Озвучка главы теперь выбирается рядом с запуском, а не в дополнительных параметрах. На экране записей первыми идут исходные озвученные версии; дубли ремонта не загромождают список. Сохранённые файлы и пробы свёрнуты ниже.
