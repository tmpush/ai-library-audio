Книжная мастерская 0.3.1 — macOS 14+, Apple Silicon (M1 и новее)

Откройте PKG: программа устанавливается в /Applications.
Python, Qwen3-TTS и FFmpeg входят в пакет. Homebrew на компьютере пользователя не нужен.
При записи образца разрешите доступ к микрофону. Для лицензии используется системная Связка ключей.
Модель скачивается отдельно через Настройки, только после нажатия кнопки загрузки.

В этой сборке используется CPU. Скорость Qwen и GPU/MPS на реальном Mac ещё не проверены.
Intel Mac не поддерживается этим пакетом.

Это тестовая сборка без Developer ID и нотариализации Apple.
macOS может заблокировать запуск. Не отключайте Gatekeeper целиком; для доверенной сборки используйте штатное подтверждение в настройках безопасности macOS.

Сервер лицензий в текущей конфигурации находится на Windows-компьютере владельца,
по адресу http://127.0.0.1:8791. На другом компьютере этот адрес не работает.
Для активации на Mac нужен общий HTTPS-сервер и сборка с его адресом.
Без активации доступны импорт и редактирование; озвучка требует лицензии.
Личные ключи и секреты сервера в пакет не включены.

Библиотека: ~/Library/Application Support/app.localbooks.studio.
Удаление .app не удаляет библиотеку и отдельно скачанную модель.
