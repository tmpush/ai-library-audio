Lunatica 0.3.2 — Windows x64

В комплекте: нативная программа, Python, ESpeech RL-V2, Qwen3-TTS, PyTorch CUDA и FFmpeg.
Установите программу в папку по умолчанию. Права администратора не нужны.
Файлы setup.exe и setup-*.bin должны находиться в одной папке.

Для русской озвучки достаточно ESpeech. Откройте Настройки → Русская озвучка · ESpeech, выберите папку с весами и устройство (CPU или NVIDIA CUDA), затем нажмите «Проверить и включить ESpeech».
Для ESpeech нужны espeech_tts_rlv2.pt, vocab.txt и папка vocos с config.yaml и pytorch_model.bin. Веса моделей в установщик не входят.
ESpeech автоматически расставляет ударения; ручные исправления имеют приоритет. В разделе «Мои голоса» доступны короткая запись до 12 секунд и запись до минуты. Обе подходят для ESpeech и Qwen. Для ESpeech рекомендуем 10–12 секунд: с длинным образцом озвучка занимает больше времени.
Для английского и других языков подключите Qwen. Если модель ещё не скачана, откройте Настройки → Скачать модель. Для уже скачанной модели выберите её папку в настройках.
В студии можно выбрать модель или оставить автовыбор по языку. Устройство сохраняется для обеих моделей и применяется к новым задачам.

Сервер лицензий: https://lunatica-license-admin.vercel.app. Для активации подключитесь к интернету.
Секреты сервера, личный ключ, книги и образцы голоса в комплект не входят.

Удаление через Настройки Windows → Приложения удаляет программу.
Библиотека, голоса и настройки в %APPDATA%\app.localbooks.studio сохраняются.
Папка модели также сохраняется.

Установщик не подписан сертификатом издателя. Windows может показать предупреждение SmartScreen.

В разделе «Готовые голоса» доступны четыре русских и четыре английских синтетических диктора. В студии можно выбрать диктора и прослушать пробу. Русский использует включённый ESpeech, английский — Qwen.
