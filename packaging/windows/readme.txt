Lunatica 0.3.2 — Windows x64

В комплекте: нативная программа, Python, ESpeech RL-V2, Qwen3-TTS, PyTorch CUDA и FFmpeg.
Установите программу в папку по умолчанию. Права администратора не нужны.
Файлы setup.exe и setup-*.bin должны находиться в одной папке.

Модель Qwen скачивается отдельно: Настройки → Скачать модель.
Для русского языка выберите папку весов ESpeech в настройках. Нужны espeech_tts_rlv2.pt, vocab.txt и папка vocos с config.yaml и pytorch_model.bin. Веса в установщик не входят.
ESpeech автоматически расставляет ударения; ручные исправления имеют приоритет. Для своего голоса запишите новый образец длительностью 10–12 секунд.
Загрузка начинается только по вашей команде. Уже скачанную модель можно выбрать в настройках.
Для компьютера без NVIDIA выберите CPU и обычный режим.

Сервер лицензий: https://lunatica-license-admin.vercel.app. Для активации подключитесь к интернету.
Секреты сервера, личный ключ, книги и образцы голоса в комплект не входят.

Удаление через Настройки Windows → Приложения удаляет программу.
Библиотека, голоса и настройки в %APPDATA%\app.localbooks.studio сохраняются.
Папка модели также сохраняется.

Установщик не подписан сертификатом издателя. Windows может показать предупреждение SmartScreen.

В разделе «Готовые голоса» доступны четыре русских и четыре английских синтетических диктора. В студии можно выбрать диктора и прослушать пробу. Русский использует включённый ESpeech, английский — Qwen.
