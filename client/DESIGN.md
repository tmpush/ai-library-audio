# Рабочее окно «Книжная мастерская»

Desktop creator utility, editorial split. Пользователь выбирает локальную книгу, проверяет главы и готовит текст к голосовой озвучке. Основное действие первого этапа — импорт книги; далее работа с конкретной главой.

Три области: библиотека 230 px, главы 260 px, текст с настройками. Пустое состояние объясняет импорт. Отдельные состояния загрузки, ошибки и подготовленного текста. Нереализованный синтез обозначен текстом, без фиктивной кнопки запуска.

Токены: фон #f4f1e9, поверхность #fffdf8, текст #252b27, вторичный #59645d, граница #d8dcd4, акцент #285d45. Тёмная тема #191e1b/#232b25/#edf1e8/#aebcaf/#39463c/#a1d8ad. Системный Segoe UI для управления; Georgia для текста книги. Размеры 13/15/18/28 px, шаги отступов 4/8/12/16/24/32. Радиус 5 px; без теней и декоративной анимации. Иконки заменены ясными текстовыми подписями.

Доступность: семантические кнопки, подписи полей, видимый focus, aria-live ошибок; адаптация до 640 px с последовательными панелями. Проверить обе темы, длинные названия, пустую библиотеку и ошибки сервера. Предварительная готовность плана 9/10. Визуальные оценки выставить после просмотра работающего интерфейса.
