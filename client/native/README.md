# Нативная Книжная мастерская 0.3

Интерфейс Windows написан на Rust с egui/eframe (OpenGL), без React, HTML, JavaScript, Tauri и WebView. Golos Text и Lora включены в executable с OFL-лицензиями в assets. Диалоги файлов — rfd / Windows; микрофон — CPAL; звук — Rodio; запись — WAV PCM16 mono 24 kHz.

## Сборка и установка

Из корня проекта:

```powershell
.venv-tts\Scripts\python.exe -X utf8 scripts/build_sidecar.py --with-tts --onedir --ffmpeg-dir build/ffmpeg-runtime
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_native.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install_desktop.ps1
```

Нужны Rust MSVC и Microsoft C++ Build Tools. Для запуска установленной программы инструменты разработчика не нужны. `Cargo.lock` фиксирует зависимости. Скрипт сборки встраивает только URL сервера лицензий и публичный ключ; приватные ключи и ключ пользователя не входят в бинарный файл.

Установщик требует закрыть программу, сохраняет прежний executable в `backups/<timestamp>` и обновляет ярлыки. Библиотека, голоса, кэш, лицензия и настройки модели остаются в `%APPDATA%/app.localbooks.studio`. `native-ui.json` хранит тему, последнюю книгу, голоса для книг и папку экспорта. Обратный переход к прежнему executable совместим с этой библиотекой; дополнительные маршруты движка не меняют старые.

## Как устроено

Rust-приложение запускает локальный `engine/books-engine.exe` без консоли. Движок остаётся на Python/PyTorch/CUDA, поскольку Qwen и его ускорение уже проверены в этом runtime. Интерфейс обращается к нему по случайному порту 127.0.0.1 с новым случайным токеном на каждый запуск. Это внутренний канал между процессами, не веб-интерфейс. Токен не сохраняется на диск. Сервер лицензий — отдельный процесс на порту 8791.

При закрытии Rust закрывает микрофон, останавливает плеер и завершает дочерний движок. Незавершённые задачи доступны для продолжения; готовые фрагменты сохраняются. Повторный запуск GUI защищён файловой блокировкой. Движок также защищает библиотеку отдельной блокировкой. Импорт, сетевые обращения, синтез и экспорт не выполняются в потоке отрисовки.

## Основной сценарий

1. «Мои книги» → «Добавить книгу…» (EPUB, FB2, PDF без OCR).
2. Открыть книгу. Справа выбрать сохранённый голос или перейти в «Мой голос».
3. «Мой голос» → прочитать предложенный текст по кнопке записи → остановить → прослушать → сохранить. Запись не включается автоматически; прекращается при уходе со страницы или потере фокуса. 10–30 секунд; автоматическая остановка через 30 секунд. Готовый WAV можно импортировать с его точной расшифровкой.
4. «Слушать пробу» генерирует только первый фрагмент текущей главы (до 250 символов), затем воспроизводит его. Проба выделена отдельно от задач озвучки книги.
5. «Озвучить всю книгу». Можно приостановить и продолжить. Очистка шума и произношение чисел включены по умолчанию для новых книг; сложные случаи можно исправить в тексте или словаре.
6. «Сохранить MP3…» выбирает файл системным диалогом. Весь результат соединяется в один MP3 128 кбит/с. Экспорт не перезаписывает существующий файл; выберите новое имя. На экране «Аудиокниги» доступны все версии, проигрывание, отдельные MP3 глав и M4B.

## Проверки

```powershell
cargo test --manifest-path client/native/Cargo.toml
cargo fmt --check --manifest-path client/native/Cargo.toml
.venv\Scripts\python.exe -X utf8 -m pytest -q
```

Тест записи использует синтетический сигнал и проверяет WAV-контракт, без включения микрофона. Интеграционные тесты проверяют ограниченную пробу, независимость полной задачи, длительность MP3, метаданные и защиту существующего файла. Реальную запись с микрофона необходимо оценивать вручную; громкость и шум зависят от устройства.

Перенос GUI не меняет скорость модели: основную работу делает прежний CUDA-модуль. Мягкая очистка снижает постоянный шум, но не является удалением любых посторонних звуков. Языковая нормализация чисел не заменяет полную морфологию русского языка.
